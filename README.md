# Санаторий «Уручье» - Веб-сайт

Курсовая работа по дисциплине **«Компьютерные языки разметки»**  

## Описание

Веб-сайт медицинского спа-курорта «Уручье», расположенного в Минске.  
Сайт предоставляет информацию о санатории, медицинских услугах, номерах и позволяет забронировать проживание.

## Технологии

- **HTML5** - семантическая разметка
- **CSS3/SCSS** - стилизация, адаптивная вёрстка
- **JavaScript** - управление DOM, загрузка данных из XML, валидация форм, слайдер новостей, hover-эффекты
- **XML** - хранение данных (новости, услуги, номера)
- **Figma** - прототипирование и макетирование

## Структура сайта

| Страница | Описание |
|----------|----------|
| `index.html` | Главная - hero, преимущества, новости |
| `about.html` | О санатории - история, описание, задачи, объекты |
| `medicine.html` | Медицинские услуги - направления |
| `rooms.html` | Номера - 4 категории |
| `booking.html` | Бронирование - форма, контактная информация, карта, обратная связь |

## Особенности

- Адаптивный дизайн (мобильные устройства, планшеты, десктоп)
- Бургер-меню для мобильных устройств
- Слайдер новостей (карусель с переключением)
- Интерактивная карта (Яндекс.Карты)
- Валидация форм на JavaScript (даты, телефон, email)
- Загрузка контента из XML-файлов
- Hover-эффекты при наведении

## Как запустить

1. Клонировать репозиторий: `git clone https://github.com/dgaf1/uruchye-sanatorium.git`
2. Открыть `index.html` в браузере или запустить через Live Server в Visual Studio Code

## Валидация

Все HTML-страницы, CSS и XML-файлы прошли проверку через W3C Validator без предупреждений и ошибок.
